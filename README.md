Cheque Management System:
Overview
The Cheque Management System is a portal designed for uploading and processing cheques. It enables users to securely upload cheque details, track cheque status, and manage approvals efficiently.
Features
Cheque Upload: Users can upload cheque images and enter relevant details.
Approval Workflow: Cheques go through an approval process before acceptance.
Status Tracking: Monitor the status of cheques (Pending, Approved, Rejected).
User Authentication: Secure login and role-based access control.
Search & Filter: Easily find cheques using filters and search functionality.
